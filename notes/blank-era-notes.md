# The 47 eras with no note

Measured over `data/regions.json` on 13 October 2026: **47 of 230 eras in 41 regions** carry no `note` (20%). Listed by whether a note would tell a reader something the panel does not already say. **No prose is drafted here**: this atlas writes only positive evidence into a data row, and a note is checkable against something already in the repo or it is not written.

How the tiers are cut (all mechanical, from the file itself):

1. **write** — the era's `filedUnder` set differs from the era before it (or it is the region's first era). The paper changes hands here, so this is where a reader is most likely to look in the wrong archive. These are the notes worth writing.
2. **optional** — the same archives as the era before. A reader who followed the previous panel is not misled by silence.
3. **quiet** — `filedUnder` is empty. The panel already prints "no archive holds this yet"; a note would only restate it unless there is a *reason* (e.g. registers did not yet exist) that can be cited.
